# 2026-09-14 方案与实现计划

## 需求到实现

- 通用识别：新增 text_align，自动注册。表头别名确定列语义，字符坐标和正文空隙确定列边界；处理贴邻金额/户名和轻微行内偏移，不按银行名或固定坐标选择分支。
- 保守行覆盖：每页需有唯一完整表头，未识别行或缺表头均记错；仅正文文本列允许紧邻续行；异常金额不依余额反推。
- 证据核对：模型新增全页文字行覆盖证据、原件是否要求流水号、提示。旧提取器默认保持严格规则。原件未声明数仍是 None，不使用提取结果自填声明数。
- 原件控制：扩展明确账期、货币及首张上页余额解析，后页上页余额按跨页控制处理。
- 可见进度：作用域内回调穿透现有提取器注册契约；模型调用前/保存后报告页码，界面计时、首份日志和模式提示。
- 输出：新增核对依据、核对提示；所有失败但有提取结果的交易保留至待核查表。
